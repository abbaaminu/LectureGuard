# LectureGuard Flutter app

See the repository [README](../README.md) for setup, Supabase migration order,
environment configuration, biometric limitations, and validation instructions.

Copy `env.example.json` to `env.json`, enter the Supabase URL and anon or
publishable client key, then run `flutter run
--dart-define-from-file=env.json`. Do not add a service-role key to the app.
